# 42school

Davide Oriani's projects from 42 school (42 Roma), collected as a read-only archive. Each folder is a copy of the latest commit on `main` of the original repository, without its history.

| Folder | Content |
| --- | --- |
| `piscine/` | C, C++ and Python piscines |
| `common-core/` | common core projects, from `libft` to `ft_transcendence` |
| `exams/` | exam exercises |
| `masteries/` | masteries projects |
| `tools/` | C project template with `libft` |

`common-core/libft` is the submitted version; `common-core/libft-extended` is the same library, extended and used in later projects.
